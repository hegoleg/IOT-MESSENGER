# Сервер (релей)

Каталог: `server/`. Стек: Node.js 20+, TypeScript, Fastify 5, ws,
better-sqlite3.

## Что делает

- принимает WebSocket `role=dev|usr` по токену;
- пересылает `msg` и `cb` между платой и клиентом;
- хранит последние 50 сообщений на токен в SQLite;
- отдаёт историю и создаёт токены по REST;
- отвечает на `ping` и сообщает `status` при connect/disconnect;
- отдаёт админ-API: список устройств, удаление, метрики.

Пользовательской логики нет — только маршрутизация.

## Схема SQLite

- `devices(token PK, created_at, last_seen)`
- `messages(token, id, from_role, ts, text, kb, PK(token,id))`

`edit: true` обновляет текст/кнопки, не меняя исходный `ts`.

## Конфигурация `.env`

```env
PORT=8080
HOST=0.0.0.0
DB_PATH=./data/iot.db
RATE_LIMIT_PER_MIN=20
LOG_LEVEL=info
# ADMIN_KEY=...
```

Если задан `ADMIN_KEY`, `POST /api/v1/devices/create` требует
`Authorization: Bearer <ADMIN_KEY>`.

## Админ-API и метрики

Все админ-эндпоинты требуют `ADMIN_KEY`; если переменная не задана — `401`.

```bash
curl -H "Authorization: Bearer $ADMIN_KEY" http://localhost:8080/api/v1/devices
curl -H "Authorization: Bearer $ADMIN_KEY" http://localhost:8080/api/v1/metrics
curl -X DELETE -H "Authorization: Bearer $ADMIN_KEY" \
  http://localhost:8080/api/v1/devices/<token>
```

- `GET /api/v1/devices` — токены, `created_at`, `last_seen`, `online`.
- `DELETE /api/v1/devices/:token` — устройство, история и живые сокеты;
  неизвестный токен → `404 { "ok": false, "error": "device not found" }`.
- `GET /api/v1/metrics` — `uptime`, `connections_dev/usr`,
  `messages_routed/stored`, `errors_400/401/413/429`.

Счётчики живут в памяти процесса и обнуляются при рестарте.

## Деплой

Режим «как в Telegram»: плата и PWA подключаются к релею наружу, публичный IP
платы не нужен. Три варианта — в `server/DEPLOY.md`:

- Raspberry Pi / домашний ПК + Cloudflare Tunnel — бесплатно, без публичного IP;
- VPS + Caddy — HTTPS/WSS и сертификат автоматически;
- Docker — `docker compose up -d --build`.

Файлы: `deploy/Caddyfile`, `deploy/iot-relay.service`,
`deploy/cloudflared.yml.example`, `server/Dockerfile`, `docker-compose.yml`.
