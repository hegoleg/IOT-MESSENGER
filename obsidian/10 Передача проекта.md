# Передача проекта

## Что уже есть

- Публичный репозиторий: https://github.com/hegoleg/IOT-MESSENGER
- GitHub Pages: https://hegoleg.github.io/IOT-MESSENGER/
- PWA: https://hegoleg.github.io/IOT-MESSENGER/app/
- Netlify (резерв и preview): https://brilliant-kashata-2a9cd6.netlify.app/

## Доступ

- **Читать** может любой: репозиторий публичный.
- **Писать** — только collaborator с правом write. Приглашение отправляется в
  GitHub → Settings → Collaborators; друг принимает его в уведомлениях.
- Для деплоя на Netlify/хостинг нужны отдельные доступы; в Git их нет.

## Что передать словами

1. Домен и хостинг, если нужен переезд.
2. Адрес релея `wss://...` и `ADMIN_KEY`, если задан.
3. Модели плат, кабели, статус проверки на железе.
4. Что именно улучшать на сайте: дизайн, тексты, новые секции.

Пароли и токены — через менеджер паролей, не в переписке и не в репозитории.

## Как работать

```bash
git clone https://github.com/hegoleg/IOT-MESSENGER.git
cd IOT-MESSENGER
npm install
npm run build
npm test

git switch -c site/improvements
# правки в landing/
git add -A
git commit -m "site: ..."
git push -u origin site/improvements
```

Дальше — pull request в `main`. GitHub Pages обновится после merge, Netlify
даст Deploy Preview для PR.

## Живой предпросмотр без пуша

На ПК друга:

```bash
npm run dev:landing:lan
```

Открыть `http://IP-друга:5174` — HMR обновит страницу при сохранении.

## Промпт для агента друга

```text
Ты работаешь в репозитории https://github.com/hegoleg/IOT-MESSENGER.
Сначала прочитай README.md, AGENTS.md, PROTOCOL.md и заметки в obsidian/.
Затем запусти npm install, npm run build и npm test.

Задача: улучшить промо-сайт в landing/. Не меняй PROTOCOL.md, shared/,
server/ и firmware/ без необходимости. Сохраняй стиль: инженерный интерфейс,
графит + кислотный лайм, моноширинные метки.

После изменений проверь npm run build:landing, покажи git diff и кратко
объясни, что изменил. Секреты и реальные токены не добавляй.
```

## Правила

- Не коммитить `.env`, `secrets.h`, базы и токены.
- Не менять контракт без `PROTOCOL.md` и `shared/types.ts`.
- В библиотеке нет `delay()`.
- Ветку `gh-pages` не редактировать вручную — её собирает workflow.
- После изменений: `npm run build`, `npm test`, для прошивки — `pio run`.
