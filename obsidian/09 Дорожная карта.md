# Дорожная карта

## P0 — до первого реального пользователя

- [ ] Проверить прошивку на живой ESP8266 и ESP32.
- [ ] Проверить USB-настройку: scan → token → set → reboot.
- [ ] Проверить Web Serial в Chrome/Edge по HTTPS.
- [ ] Прогнать QR-сценарий: сайт → телефон → PWA → `/start`.
- [ ] Проверить релей на внешнем домене с WSS и валидным сертификатом.

## P1 — удобство и надёжность

- [x] LAN-режим ESP: `ws://IP:81`, mDNS `_iotbot._tcp` (`IoTBotLAN`).
- [ ] ESP из другой сети: инструкция по пробросу порта и DDNS.
- [ ] PWA на ESP: отдача статики через LittleFS.
- [ ] HTTPS/WSS на ESP с сертификатом.
- [ ] Web Push при сообщении от платы, когда PWA закрыта.
- [ ] Presence без опроса всех токенов (мультиплексирование на сервере).
- [ ] Ограничение CORS по домену PWA.
- [ ] Тесты компонентов PWA (React Testing Library).
- [ ] Тесты serial-протокола на стенде/эмуляторе.
- [ ] Кастомный домен для сайта и PWA.

## P2 — развитие

- [ ] Роли и несколько пользователей на устройство.
- [ ] OTA-обновление прошивки через релей.
- [ ] Шифрование секретов в EEPROM/NVS.
- [x] Метрики релея: `/api/v1/metrics` (админ).
- [ ] Health-дашборд и графики метрик.
- [ ] Мобильная установка из магазина приложений (обёртка PWA).
- [ ] Выбрать лицензию проекта и оформить `LICENSE`.

## Идеи

- [ ] Шаблоны прошивок: реле, датчик, камера.
- [ ] Библиотека готовых inline-меню.
- [ ] Экспорт истории в JSON/CSV.
- [ ] Тёмная/светлая тема PWA.
- [ ] Локализация сайта на английский.
