# Запуск и проверки

## Что нужно

- Node.js 20+ (проверено на 22);
- npm;
- PlatformIO для прошивки;
- Chrome/Edge для Web Serial.

## Установка

```bash
npm install
cp server/.env.example server/.env
cp web-app/.env.example web-app/.env          # необязательно
```

## Локальный запуск

```bash
# терминал 1 — релей :8080
npm run dev

# терминал 2 — PWA :5173
npm run dev:web

# сайт :5174
npm run dev:landing
```

## Симулятор ESP

```bash
npm run sim:esp -- --telemetry=5
```

Печатает токен, отвечает на `/start`, `/on`, `/off`, `/status`, `/stop`,
кнопки и телеметрию. Плата не нужна.

## Тесты

```bash
npm test
```

- 30 юнит-тестов PWA (Vitest): протокол, формат, storage, URL релея.
- 10 интеграционных тестов сервера: симулятор ESP, админ-API, метрики,
  удаление устройства, обрезка истории, edit, 413/429/401.
- `npm run smoke` — HTTP/WS smoke релея.

## Сборка

```bash
npm run build         # shared + server + web-app + landing
npm run build:site    # сайт + PWA для деплоя
```

## Прошивка

```bash
cd firmware/examples/quickstart
pio run -e nodemcuv2 -e esp32dev
cd ../../..
npm run firmware:export
```

Если `pio` не в PATH: `python -m platformio run ...`.

LAN-пример (без релея):

```bash
cd firmware/examples/lan
cp include/secrets.h.example include/secrets.h
python -m platformio run -e nodemcuv2 -e esp32dev
python -m platformio device monitor -b 115200
```

В мониторе будет строка `ws://<IP>:81/ws?token=...` — этот адрес вводится
в PWA в режиме «Локальная сеть».

## Проверка PWA

- Открыть `http://localhost:5173`.
- Мастер: адрес релея → «Проверить» → создать устройство.
- Отправить `/start` (с симулятором или платой).
- Проверить установку PWA в Chrome.

## Проверка сайта

```bash
npm run build:site
npm run preview:landing
```

Для GitHub Pages локально можно собрать с `SITE_BASE=/IOT-MESSENGER/` и
разложить `landing/dist` под префиксом `/IOT-MESSENGER/`.

## Windows

- `curl.exe` вместо `curl`, если PowerShell подменяет команду.
- Порт релея 8080 и сайта 5174 открыть в брандмауэре для LAN.
