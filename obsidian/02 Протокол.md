# Протокол

Канонический контракт: [PROTOCOL.md](https://github.com/hegoleg/IOT-MESSENGER/blob/main/PROTOCOL.md).
TypeScript-зеркало: [shared/types.ts](https://github.com/hegoleg/IOT-MESSENGER/blob/main/shared/types.ts).

## Транспорт

- Облако: `wss://HOST/ws?role=dev|usr&token=...`
- LAN (в протоколе): `ws://IP:81/ws?token=...`
- HTTP fallback: `POST /api/v1/msg` с `Authorization: Bearer <token>`

## Пакеты

| Тип | Назначение |
| --- | --- |
| `msg` | текст, инлайн-клавиатура, edit |
| `cb` | нажатие кнопки (`d` = callback_data) |
| `status` | online/offline платы (генерирует сервер) |
| `ping` / `pong` | heartbeat |
| `err` | ошибка с кодом |

### msg

```json
{
  "v": 1,
  "type": "msg",
  "id": "m_1042",
  "from": "dev",
  "ts": 1794905120,
  "text": "Температура: 24.5°C",
  "edit": false,
  "kb": [[
    { "t": "Полив", "d": "pump_on" },
    { "t": "Статус", "d": "status" }
  ]]
}
```

### cb

```json
{ "v": 1, "type": "cb", "id": "m_1042", "from": "usr", "d": "pump_on" }
```

### status

```json
{ "v": 1, "type": "status", "dev_online": true, "last_seen": 1794905125 }
```

## Лимиты

- пакет — 1024 байта;
- текст — 512 байт;
- клавиатура — до 3 рядов × 3 кнопки;
- история — 50 сообщений на токен.

## Heartbeat

- ESP шлёт `ping` каждые 25 секунд.
- Сервер отвечает `pong`.
- Нет `pong` 5 секунд → разрыв и переподключение через 3 секунды.

## LAN-режим

- ESP поднимает `ws://<IP>:81/ws?token=<LAN_TOKEN>` и mDNS `_iotbot._tcp`.
- Токен проверяется на плате: неверный → `err` 401 и закрытие.
- После подключения плата отправляет `status` с `dev_online: true`.
- Входящие `msg`/`cb` — до 30 в минуту на клиента.

## Ошибки

Коды: `400` (битый JSON), `401` (токен), `413` (пакет > 1024),
`429` (rate limit).

## REST

- `POST /api/v1/devices/create` → `{ "token": "..." }`
- `GET /api/v1/history?token=...&limit=50` → `{ "messages": [...] }`
- `POST /api/v1/msg` → `202 { "ok": true }`
- `GET /api/v1/health` → `{ "ok": true, "v": 1, "uptime": 3600 }`

## Админ-API

Требует `Authorization: Bearer <ADMIN_KEY>`; без `ADMIN_KEY` — `401`.

- `GET /api/v1/devices` → `{ "devices": [{ token, created_at, last_seen, online }] }`
- `DELETE /api/v1/devices/<token>` → `{ "ok": true }` или `404`
- `GET /api/v1/metrics` → соединения, сообщения, ошибки 400/401/413/429
