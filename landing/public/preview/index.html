if (message == "/led") {
  led = !led;
  digitalWrite(LED_PIN, led);
  sendMessage(led ? "Свет включён"
                  : "Свет выключен");
}

if (message == "/status") {
  sendMessage(readSensors());
}

Прошейте
плату из браузера.

Chrome или Edge на компьютере, USB-кабель и плата ESP8266 или ESP32. Прошивка, Wi-Fi, релей и токен — без PlatformIO и терминала.

Шаг 01 — прошивка

Подключите плату по USB

Нажмите «Прошить плату», выберите COM-порт и дождитесь окончания. Плата перезагрузится в режим настройки.

Web Serial недоступен. Откройте страницу в Chrome или Edge на компьютере по HTTPS. Разрешите браузеру доступ к USB-порту.

IoTBot Quickstart · ESP8266 · ESP32 · Wi-Fi 2,4 ГГц

Шаг 02 — настройка

Wi-Fi, релей и токен

Закройте окно установки и подключитесь к плате: страница найдёт Wi-Fi сети, создаст токен на релее и запишет настройки в память платы.

Для настройки по USB нужен Chrome или Edge на компьютере (HTTPS или localhost). С телефона прошивка недоступна.
